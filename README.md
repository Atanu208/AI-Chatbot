## 🔴 AI Chatbot

This repository demonstrates how to **set up and run Meta’s LLaMA 3.2 models (1B & 3B parameters) locally** and build your own AI-powered chatbot.
It covers everything from **downloading and running models offline** to **integrating with Jupyter Notebook, Python, and Gradio** for creating a fully functional chat interface.

### ✨ Features

* Run **LLaMA 3.2 (1B & 3B)** models locally on your PC or laptop
* Works **offline** – no API costs or internet dependency
* Interactive chatbot with **real-time responses**
* Integration with **Gradio UI** for web-based chat
* Simple setup using **Olama (Ollama)** and Python
* Supports Q\&A, text generation, and coding help

### 🛠️ Tech Stack

* **Meta LLaMA 3.2 Models** (1B & 3B)
* **Python** (Jupyter Notebook, VS Code)
* **Gradio** for chatbot UI
* **Olama/Ollama** for running models locally

### 🚀 How to Use

1. Install [Ollama] on your system
2. Download LLaMA 3.2 models (1B or 3B)
3. Run models via terminal or Jupyter Notebook
4. Launch the chatbot with Gradio UI
5. Start chatting with your **offline AI assistant** 🎉

👉 This repo makes it easy to **turn your computer into a private AI chatbot** without depending on cloud APIs.
